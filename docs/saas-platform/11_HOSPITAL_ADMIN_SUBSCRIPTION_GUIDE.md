# Hospital Admin SaaS Subscription Guide

## 1. Overview
The Hospital Admin Dashboard (`/hospital/admin`) provides hospital executives with visibility into their organization's active license tier, consumption metrics, subscription tax invoices, and support authorisations.

## 2. Key Sections
- **SaaS Subscription & Billing**:
  - View current plan tier, renewal date, and monthly cost.
  - Download official GST-compliant tax invoices for hospital accounting.
- **Quota & Usage Metering**:
  - Track live staff account headcount vs subscription allowance.
  - Track monthly patient registration volume against plan limits.
  - Monitor encrypted cloud storage consumption (PACS imaging, diagnostic PDFs).
- **JIT Support Authorizations**:
  - Review technical support requests from ASRTAVA platform engineers.
  - Authorize time-bounded (30m/60m) access or revoke active sessions.
- **Self-Service Data Portability**:
  - Request encrypted full tenant backup archives (JSON / CSV).
  - Download links are cryptographically signed and expire after 7 days.
