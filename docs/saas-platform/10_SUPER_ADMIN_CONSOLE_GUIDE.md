# Super Admin SaaS Console User Guide

## 1. Overview
The Super Admin Console (`/super-admin`) provides platform owners with high-altitude governance, financial telemetry, and lifecycle controls across all subscribed healthcare institutions.

## 2. Console Modules
- **Dashboard & KPIs**: Real-time MRR, ARR, subscribed hospital counts, active vs trial distribution, total managed patients, and cloud storage allocation.
- **Hospitals & Tenants Directory**: Search by hospital legal name, slug code, or city. Filter by status (`Active`, `Trial`, `Suspended`). View bed capacity and enrolled patient volumes.
- **Lifecycle Controls**: Suspend or reactivate tenants with mandatory audit reasons.
- **Subscription Plans & Entitlement Matrix**: Review Starter, Professional, and Enterprise pricing in INR with feature breakdown.
- **SaaS Invoices & Revenue**: Separate platform software billing registry displaying invoice numbers, hospital names, subtotal, GST (18%), and payment status.
- **JIT Support Access**: Initiate zero-standing-privilege support requests linked to ticket numbers.
- **Announcements**: Broadcast scheduled maintenance windows and module release notices across tenant workspaces.
- **Security & Telemetry Audit Stream**: Immutable real-time stream of authorization checks, RLS policies, and critical administrative operations.
