# Clinical Document Control & SOP Versioning Validation

## 1. Scope
Management of Standard Operating Procedures (SOPs), clinical practice guidelines, policies, and controlled medical forms.

## 2. Document Control Lifecycle
1. **Drafting**: Author prepares clinical SOP with scope, responsibilities, and step-by-step procedures.
2. **Review & Approval**: Quality Manager and Medical Superintendent approval sign-offs.
3. **Publication & Version Bump**: Document receives active status and unique code (e.g. `SOP-CLIN-001 v2.0`). Previous versions automatically marked `ARCHIVED`.
4. **Staff Dissemination & Read Receipts**: Clinical staff must acknowledge reading new versions. System tracks compliance percentages per department.
5. **Periodic Review Trigger**: Automated notification 60 days prior to mandatory annual/biennial review date.
